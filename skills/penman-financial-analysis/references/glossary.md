# 模型口径词典

|符号|执行时的含义与核对点|章节|
|---|---|---|
|CSE 或 B|普通股股东账面权益，先剔除优先索取权，确定是否归属母公司。|2、9|
|d|净分配，现金分红及回购减发行。总额与每股口径需要独立核对。|2、9|
|综合收益|权益变动中扣除与所有者净交易后的部分。检查绕过净利润列报的项目。|9|
|RE|本期普通股综合收益减要求权益回报率乘期初普通股账面权益。|5|
|AEG|含上期分配再投资收益的本期盈利超过上期盈利正常增长后的差额。|6|
|NOA / NFO|经营资产减经营负债 / 金融负债减金融资产。仅有普通权益时 NOA−NFO=CSE。|8、10|
|OI / NFE|税后经营利润 / 税后净融资费用。非控股权益等其他索取权须在归属桥中另列。|10|
|FCF|经营活动可分配的现金，统一经营边界后 FCF=OI−ΔNOA。|8、11|
|RNOA / NBC|税后净经营资产回报率 / 税后净借款成本，列明对应资本分母的时点。|12|
|PM / ATO|经营利润率 / 净经营资产周转率，同期口径下 RNOA=PM×ATO。|12|
|核心盈利|为预测持续获利能力而识别的经常性盈利；分类判断需注明证据。|13|
|ReOI|税后经营利润扣除期初净经营资产的经营资本费用。|14|
|继续价值|显式期后剩余收益或现金流在预测终点的现值，需再折回估值日。|4–6、14|
|价值风险剖面|在明确的经营或融资状态下逐一计算价值，给出状态间的暴露。|19–20|
