# 从一张资产负债表到一个可以质疑的价格

Stephen H. Penman，《Financial Statement Analysis and Security Valuation》，2013 年国际版第五版，ISBN 9780071326407。以下页码指书页印刷号码。例如第 694 页位于此 PDF 第 714 页。企业例子属于该版历史案例。

Penman 把估值看成一项预测工作。先问当前账面已经承认了多少净资源，再问未来经营能否赚回这些资源的机会成本。最后把仍需预测的部分与市场价格相对照。清洁盈余关系把期初权益、综合收益、与普通股东的净交易和期末权益连起来，预测错误可以沿这条链回查。

|章节与起始印刷页|读者可完成的任务|
|---|---|
|1–3（2、32、74）|辨认证券持有人及其权利，从业务、报表联系、可比对象与资产项目选择估值起点。|
|4–7（110、140、178、210）|对照现金与应计口径，用账面权益或下一期盈利作锚，拆出价格要求的未来表现。|
|8–11（234、258、292、342）|从股东权益、损益和现金流重构经营与融资活动，核对两个资金来源的索取权。|
|12–13（364、392）|拆解净经营资产回报、杠杆及其变化，区分持续经营改善、一次性事项与资本投入。|
|14–16（436、480、504）|从企业经营价值桥接到普通股价值。先做简单预测，再用竞争条件、收入、利润率、周转和资本需求编制相互勾稽的预测。|
|17–18（554、590）|追踪确认时点如何改变当期利润和账面基数，审阅现金兑现、准备金、利润释放与披露质量。|
|19–20（642、680）|把经营驱动的波动传到股东价值，并按债务期限估算哪些情景无法还本付息。|

使用时先确定问题是权益估值、经营价值还是按期偿债，再查相应卡片。经营和金融活动的划分取决于商业模式。历史会计制度、案例公司、信用评分样本与资本成本均带有时间和适用对象。
