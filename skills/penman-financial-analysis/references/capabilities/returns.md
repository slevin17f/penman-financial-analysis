# 拆解普通股回报率的经营与杠杆贡献

## R — 来源

第12章，印刷页365–373（财务杠杆、经营负债杠杆），373–380（利润率、周转率与驱动因素）。

## I — 分清盈利从哪里来

同样的权益回报可能来自产品利润、较少的资本占用，也可能来自以低于经营回报率的成本举债。先用重构后的报表把三者分别量化，再问负债利差缩小时股东回报如何变化。

## A1 — 书例与合成演练

第368–369页用 General Mills 演示经营回报下滑后杠杆如何放大亏损；其非控股权益处理见 Box 12.5。合成例中平均 NOA 120、平均 NFO 40、平均 CSE 80，销售200、税后经营收益18、税后净融资费用2。利润率9%乘周转率1.6667得到 RNOA 15%，净借款成本5%、财务杠杆0.5。故 ROCE=15%+0.5×(15%−5%)=20%，与16/80一致。

## A2 — 触发

适用于“ROE 很高是生意好还是负债多”“比较薄利快销和高毛利企业”“利差反转时股东回报如何变化”。科目归属有争议先重构报表；利润持续性另查核心盈利。

## E — 执行与交付

1. 从同口径重构表取期间销售、税后综合经营收益 OI、税后净融资费用 NFE、归属普通股的综合收益 CI，以及 NOA、NFO、CSE 的期初期末数。以下示例分母统一用同期间平均余额，重大期中借贷可用更高频平均数。
2. RNOA=OI/平均NOA。把它写成经营利润率 OI/销售×经营资产周转率 销售/平均NOA，继续按成本费用率和主要经营资产、负债占销售比例找出变化源。销售以外的经营收益若重大，应单列其贡献。
3. 简单资本结构下，FLEV=平均NFO/平均CSE，NBC=NFE/平均NFO。核对 CI/平均CSE=RNOA+FLEV×(RNOA−NBC)。有净金融资产时改列净金融资产占权益比例，以及其收益率 RNFA，股东回报=RNOA−(平均NFA/平均CSE)×(RNOA−RNFA)。
4. 需要解释供应商信用时，按税后短期借款率估经营负债的隐含资金成本；无经营负债时的资产回报以 OI 加回估算隐含利息后除以平均经营资产。注明估算率，并给出该率变化对解释的影响。
5. 交付利润率、周转率、利差、杠杆及其对权益回报的百分点贡献，并列出直接核算与分解结果。合并含非控股权益时先算全体普通股回报，再分到归母股东。

## B — 边界

净融资接近零时 NBC 会被小额分母放大，改用金额桥 CI=OI−NFE；负权益或负 NOA 时单列分母与业务原因。分解说明会计期间的贡献，无法仅凭恒等式推断举债会提高企业价值。
