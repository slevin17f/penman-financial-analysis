# 把经营战略写成可勾稽的预测报表

## R · 原书定位

第 16 章印刷页 505–515 从经营驱动因素及其变化组织信息；页 515–525 编制预测报表并核验两条权益路径；页 528–532 设置红旗和战略情景。框 16.4 的 Nike 历史预测把代工成本、广告投放与应收、存货和产能分别建模。

## I · 解释

新增销售额会同时改变税后利润和占用的资本。只有把二者放在同一个预测期里，才能判断战略贡献的 ReOI。经营决策先决定现金余缺，融资与分配政策再决定谁持有余款、谁承担缺口。

## A1 · 合成演练

期初 NOA 100、净金融负债 NFO 40。本年收入 240，税后经营利润率 8%，目标年末销售/NOA 为 2，经营必要报酬率 10%。得到 OI 19.2、期末 NOA 120、ReOI 9.2、自由现金流 −0.8。税后借款利率 5%，净分配 3，则净财务费用 2，期末 NFO 为 45.8。期末普通股权益同时等于 120−45.8 和 60+17.2−3，均为 74.2。销售增长需要融资，即使企业盈利。

## A2 · 触发

用户提供战略、行业变量或多期预测，请求估算经营价值、校验模型或检验扩产与涨价情景时使用。仅有历史财报且无未来驱动信息，可先用简单预测建基准。

## E · 执行与验收

1. 按预测年建列。每项关键假设注明来源日期、经营依据和可推翻该假设的迹象。区分管理层可选择的事项与价格、竞争等外部条件。
2. 用销量、价格或分部汇总销售。分别预测税后核心销售利润率、核心其他经营收益和非常项。避免一次性项目重复进入核心利润率。
3. 从应收、存货、固定资产、经营负债的周转或占收比得到期末 NOA。用总周转简化时必须注明所用的期末、期初或平均资本定义。若历史指标采用平均余额，不能直接以销售除以该指标当作期末 NOA。
4. 按年算 OI、ReOI = OI − r × 期初 NOA、FCF = OI − ΔNOA。预测净分配 d（分红加回购减发行）与税后净财务费用 NFE。期末 NFO = 期初 NFO + NFE + d − FCF。若给定杠杆目标则反求 d；融资转为净金融资产后，用对应的金融收益率。
5. 每年交叉验算 CSE = NOA − NFO = 期初 CSE + 综合收益 − d（简单普通股口径，综合收益 = OI − NFE）。逐项解释差异。对照产能、信用期限等约束；若现金持续累积，追问资金用途。用同一账务模型重算一个竞争加剧或追加投资情景，并把按期初资本核算的 ReOI 传给经营估值。

## B · 边界

合并、外币换算、股权激励、少数股东和优先股等可能改变资本与盈利归属，应先补桥接表。仅用平衡项强制报表配平会掩盖产能瓶颈。没有终值依据时，交付明细预测、已解释的现金缺口及尚待验证的长期驱动。
