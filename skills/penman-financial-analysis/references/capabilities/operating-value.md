# 用剩余经营收益估算经营价值

## R · 原书定位

第 14 章印刷页 438–449、463–468 连接经营资产、经营资本成本与企业倍数。第 15 章页 482–491 从报表出发建立无增长和有增长基准。框 15.1 用 Nike 的报表演示净金融资产如何进入普通股价值桥。

## I · 解释

经营资本每多投一元，就要多赚一元资本的机会成本。设 r 为年度税后经营必要报酬率，以期初净经营资产 NOA 计费。第 t 年剩余经营收益 ReOI_t = 税后经营利润 OI_t − r × NOA_(t−1)。这解释了为什么利润可以增加而 ReOI 持平。估值应预测完整 OI；用核心利润代表未来时，明确非常项未来期望值的假设。

## A1 · 合成演练

期初 NOA 为 100，期末为 120，本期核心 OI 为 15，r 为 10%。本期核心 ReOI 为 5。若新增资产只赚 10%，下一期 OI 为 17，ReOI 仍为 5。假定其后 ReOI 永远为 5，则当前经营价值为 120 + 5/10% = 170。若净金融负债公允价值为 30，且无其他优先请求权，普通股价值为 140。另一情景让全部 120 继续赚 15%，下一期 OI 为 18，ReOI 为 6。后续增长仍需另作假设。

## A2 · 触发

用户问业务创造了多少超额收益、企业市净率溢价有何依据，或要先用历史报表建立简单估值基准时使用。若用户给出多期销售、利润率与资本需求假设，转入全信息预测；若要逆推当前价格，先明确价格对应经营或权益。

## E · 执行与验收

1. 对齐估值日、币种和单位，取得期初与期末 NOA、核心税后 OI、r 及普通股以外的索取权。核对净金融资产的正负号。
2. 计算当期核心 ReOI。分别列示新增投资只赚必要报酬、或继续赚当前核心经营回报的下一年 OI 与 ReOI。
3. 经营价值 = 当前 NOA + 明确预测期每年 ReOI 的现值 + 期末延续价值的现值。若第 T 年后 ReOI 以固定 g 永续增长，延续价值为 ReOI_(T+1)/(r−g)，只对超额收益资本化，该结果位于第 T 年末，再除以 (1+r)^T 折回估值日。给出支持 g 的竞争和再投资条件。
4. 从经营价值扣净金融负债的市场价值，加回净金融资产（两种表示择一），再扣尚未包含的少数股东权益、优先股或期权等索取权。仅当账面值可近似市值时才用账面负债。
5. 交付从 NOA 到经营价值再到普通股价值的金额桥、折现口径与至少一个可改变溢价的情景。经营市净率为经营价值/NOA，远期经营市盈率为经营价值/下一期税后 OI，分母为零时留空。

## B · 边界

当 g ≥ r 时常增长永续公式失效，改用显式竞争消退过程。持续亏损、经营收缩或竞争侵蚀可能令未来 ReOI 低于当前水平；平推值也会高估。杠杆变化导致的每股盈利增长需要另拆融资效应。利息已从 OI 剔除时，避免在净债务桥中重复计入融资成本。
