# Penman 财务报表分析与证券估值 Skill

给出两期财报、权益变动表和估值日价格，可以用这个中文 Skill 把利润和资本重构到同一口径，再判断价格中有多少价值依赖未来表现。若只关心一个问题，例如回购怎样影响每股收益，或某年到期的债务有没有现金覆盖，也可以直接提问。

## 安装

在已安装 Git 的 macOS 或 Linux 上，将仓库中的技能目录复制到个人 Codex 技能目录。若已有同名技能，先核实版本。

```sh
git clone https://github.com/slevin17f/penman-financial-analysis.git
mkdir -p ~/.codex/skills
cp -R penman-financial-analysis/skills/penman-financial-analysis ~/.codex/skills/
```

在新会话中输入 `$penman-financial-analysis` 并附上数据。也可直接阅读[技能入口](skills/penman-financial-analysis/SKILL.md)及其能力卡。

## 一个能核对答案的例子

> 用 Penman 的剩余收益法估值。假设公司只有普通股，无债务，以总额计，期初账面权益 100，未来一年综合收益 12，净分红 10。此后账面权益、收益和分红均按 2% 永续增长。股权资本成本为 10%。请用分红和异常盈利增长交叉验证，并指出哪项假设支撑了账面溢价。

在这个合成例子中，期末权益为 102。次年收益为 12.24，股东要求首年回报 10，首年剩余收益为 2。三种方法可对到同一个时点。

|从哪里开始|计算|价值|
|---|---|---|
|期初账面权益|100 + 2 ÷ (10% − 2%)|125|
|下一期分红|10 ÷ (10% − 2%)|125|
|下一期盈利|第二年的异常盈利增长 = 12.24 + 10% × 10 − 1.10 × 12 = 0.04。价值 = [12 + 0.04 ÷ (10% − 2%)] ÷ 10%|125|

25 的溢价来自假设公司能持续赚取超过资本成本的回报。若从第一年开始回报率即降至资本成本，未来剩余收益为零，权益价值回到账面 100。真实分析可把竞争导致超额回报衰减所需的年数作为敏感性变量。

## 能做哪些分析

- **重构报表**。拆开股东交易、经营与融资，按一致边界核对净经营资产、税后经营利润和自由现金流。
- **估值与反推**。用账面权益、远期盈利或经营资产作锚，检查市场价格所要求的增长。
- **预测与质量检查**。区分经常性盈利和一次性项目，把业务假设传导至预测报表，检验会计选择对跨期利润的影响。
- **股权与债务风险**。比较不同经营情景下的条件回报，逐期检查偿债现金和再融资依赖。

依据 Stephen H. Penman, *Financial Statement Analysis and Security Valuation*, 5th ed., McGraw-Hill International Edition, 2013，ISBN 9780071326407。卡片附原版印刷页定位和独立编制的算例。本项目为中文方法学习工具。
